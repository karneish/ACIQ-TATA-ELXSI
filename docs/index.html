04

Fairness and anti-starvation

The brief asks for fairness and absence of starvation. What is measured, and what is not, is stated plainly.

~1 %
two flows in the same class share the link within ~1 % (Jain ≥ 0.95; 7/7 live tests)
3.12 / 1.81 / 1.16 / 3.91
class floors (Mbps) scale proportionally under a 10 Mbps cap, summing to exactly 10.00 — no class dropped, degraded=true
not measured
per-flow starvation duration. The dashboard exposes per-class backlog only; this is a stated limitation

Class-level Jain is recorded every run (0.333) but classes carry different weights — interactive gets 8× bulk — so equal shares are the wrong target. The guarantee verified instead is: sum(rates) ≤ capacity, no class below its (scaled) floor, and no class silently dropped.

06

Reproduce it

The controller needs root and Linux network namespaces — a host, not a browser.

# clone and install
git clone https://github.com/karneish/ACIQ-TATA-ELXSI.git
cd ACIQ-TATA-ELXSI
python3 -m venv .venv && . .venv/bin/activate
pip install -e .

# full suite (1579 tests)
python -m unittest discover -s tests -t .

# the DEV band + judged verdict
sudo ./testbed/run_round3_batch.sh
tools/verify_round3.py
